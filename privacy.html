隱私權政策

最後更新：2026-10-05

資料存取

FAAS Daily Drive Sync 會在使用者明確授權後存取其 Google Drive。存取目的僅限於讀取、建立及更新使用者指定資料夾中的臺灣公開市場資料與相關品質檢查結果。

資料使用與保存

工具取得的 Google Drive 資料只用於執行每日市場資料同步、合併、去重與驗證。檔案保存在使用者自己的 Google Drive 中；工具不建立供第三方使用的使用者資料庫。

資料分享

Google 使用者資料不會出售、出租、用於廣告，也不會提供給第三方。除非法律要求，工具不會向外部單位披露使用者資料。

資料保護與撤銷

OAuth 憑證儲存在 GitHub Actions 的加密 Secrets 中，不會放入公開程式碼。使用者可隨時在 Google 帳戶的第三方應用程式存取權設定中撤銷授權，並可直接刪除 Google Drive 中由工具建立的檔案。

Google API 政策

本工具對 Google API 取得資訊的使用與傳輸，遵守 Google API Services User Data Policy，包括 Limited Use 規定。
